# 概率区域暗色主题修复实施文档

## 问题与范围

概率卡片使用固定的浅色背景、边框和文字颜色，与 Gradio 暗色主题的全局排版规则混用。需要让 Choice、Noul、Score 的概率标题、选项文字、百分比与进度条在亮色和暗色主题中均清晰可读。本机页面与 ModelScope 共用这段代码；Hugging Face 静态入口嵌入 ModelScope，因此同步生效。

## 实施步骤

1. 将页面样式从 `core/bit_jev/web/app.py` 拆分到 `theme.py`，以 Gradio 主题变量设置概率卡片的背景、边框、文字和进度条底色；显式覆盖标题、选项及百分比的文字颜色，避免 Markdown 全局颜色覆盖。暗色主题使用更亮的进度条。
2. 在 `test/preview_web_themes.py` 提供不下载模型的三题型双语预览，使用正式概率 HTML 和 Gradio 5 主题，分别检查亮色、暗色和窄屏显示；运行现有结果呈现、表单、版本及空间配置检查。
3. PyPI 包从 0.13.12 升为 0.13.13；项目发布版本记为 v0.19.12（v0.19.11 已用于本地实验记录）。更新版本日志、项目总览及当前安装版本引用。
4. 检查发行包并发布 PyPI，之后重建 ModelScope Space、同步模型卡与 GitHub；Hugging Face iframe 继续使用同一个运行页面。

## 验收

- 三题型的标题、选项文字与百分比在两种主题均可读，长选项可换行。
- 空说明默认回退、选项增删和 API 输入输出保持既有行为。
- 本地实验记录及 ExTernD 文件不进入本次公开提交。
